# 财智8 Web 版 — 功能与架构设计

> 本文档描述本项目（仿「财智8」的个人记账理财 Web 应用）的整体架构、数据模型与核心业务规则，供二次开发参考。

## 1. 技术栈

| 层 | 技术 |
| --- | --- |
| 前端 | Vue 3 + TypeScript + Vite + Element Plus + Pinia + Vue Router + ECharts |
| 后端 | FastAPI + SQLAlchemy 2.x + Pydantic v2 |
| 存储 | SQLite（多文件：通用库 + 每账本一库） |
| 启动 | `main.py` 一键启动（开发 / 生产 / 初始化 / 演示） |

## 2. 运行模式

```powershell
python main.py          # 开发：后端 8000 + 前端 Vite 5173（热更新）
python main.py --prod   # 生产：构建前端后由后端单进程托管 8000
python main.py --init   # 重置为初始空账本
python main.py --demo   # 生成覆盖全部功能的演示数据
```

## 3. 数据存储设计

数据目录为 `backend/data/`：

- **common.db**：通用设置 —— 账本登记、收支分类、币种、汇率、存款利率、交易费率、产品资料（Instrument）与价格（InstrumentPrice）。
- **ledger_{id}.db**：每个账本一个独立文件 —— 账户、人员/机构、流水、标签、预算、持仓、借贷、计划。

请求通过 `X-Ledger-Id` 请求头选择当前账本；后端按需 ATTACH 对应账本库。API 统一前缀 `/api/v1`。

## 4. 核心业务规则

### 4.1 账户与余额

- 账户类型：现金 / 储蓄卡 / 信用卡 / 钱包 / 储值 / 投资（证券、基金、理财、债券、贵金属、外汇、网贷等）。
- **铁律**：账户余额 = 该账户所有流水之和。
- 期初余额以 `type='adjust'`（期初余额）流水记录，**不**使用单独的 initial_balance 字段。
- `adjust` 流水为带符号金额，不计入收入/支出统计，用于：期初余额、余额调整、货币兑换。
- 余额限制：现金/钱包/储蓄卡不可为负；信用卡受 `credit_limit` 限制。

### 4.2 记账操作

支出 / 收入 / 转账 / 货币兑换 / 分拆 / 预付（递延）/ 借入 / 借出 / 工资收入等，均落地为一条或多条流水，并实时变更账户余额。

### 4.3 投资与持仓

- 投资账户 `current_balance` 仅表示**可用现金**；持仓市值、网贷应收单独在净值中统计，避免重复计算。
- 资金流：先从现金/储蓄卡转入投资账户（账户有现金），再买入产品扣减现金。
- 买入：在资金账户记一笔支出并创建/更新持仓；卖出：记一笔收入并减少/删除持仓。
- 持仓字段：数量、成本、最新价；市值 = 数量 × 价格，盈亏 = 市值 − 成本。

### 4.4 行情同步

通过新浪行情接口同步股票/基金/贵金属/外汇牌价，写入 `InstrumentPrice` 与币种汇率，供持仓估值与统计使用。

## 5. 目录结构

```
MW/
├── main.py                # 一键启动入口
├── backend/
│   ├── requirements.txt
│   └── app/
│       ├── main.py        # FastAPI 应用与迁移
│       ├── models.py      # SQLAlchemy 模型
│       ├── schemas.py     # Pydantic 模型
│       ├── demo.py / seed.py
│       ├── api/           # 按业务域拆分的路由
│       ├── core/          # 配置与数据库
│       └── services/      # 余额、行情等服务
└── frontend/
    └── src/
        ├── api/           # 接口封装
        ├── stores/        # Pinia 状态
        ├── views/         # 页面
        ├── components/    # 复用组件
        └── router/        # 路由
```

## 6. 已实现功能一览

- 多账本、账户管理、收支/转账/兑换/分拆/借贷/工资记账
- 流水筛选、搜索、分页、编辑、删除
- 投资：证券、基金、理财、债券、贵金属、外汇、网贷（P2P）独立页面与买卖
- 预算、收支分类、人员/机构、财务计划与提醒
- 统计与仪表盘（收支概览、分类饼图、趋势图、投资收益报表）
- 行情/汇率同步
- 响应式：桌面端顶部导航 + 移动端底部 Tab
